# Contract: land report artifact schema

Persisted at `.maverick/runs/<run-id>/land-report.json` (atomic write) on
every land evaluation. Treated as a **stable public contract**
(constitutional rule: action outputs are public interfaces) — additive
evolution only. `land-report.md` is the human/PR rendering of the same data
and carries no independent fields.

## `land-report.json`

```json
{
  "schema_version": 1,
  "run_id": "a1b2c3d4",
  "created_at": "2026-07-24T15:04:05Z",
  "dry_run": false,
  "verification": "verified | conditionally-verified | blocked",
  "totals": { "resolved": 3, "waived": 1, "open": 0, "pending_reconcile": 0 },
  "specs": [
    {
      "owner_spec": "052-conditional-landing",
      "counts": { "resolved": 2, "waived": 1, "open": 0, "pending_reconcile": 0 },
      "entries": [
        {
          "bead_id": "ma-0042",
          "bucket": "resolved | waived | open",
          "question": "…",
          "adopted_answer": "…",
          "final_answer": "… | null",
          "alternatives": ["…"],
          "severity": "low | medium | high",
          "severity_defaulted": false,
          "is_legacy": false,
          "source_bead": "ma-0031",
          "affected_change_ids": ["zzkw…", "rlvk…"],
          "waiver": { "by": "…", "at": "2026-07-24T14:00:00Z", "reason": "…" },
          "reconcile": {
            "status": "reconciled | needs-interactive-review | skipped | pending | null",
            "reconciled_answer": "… | null",
            "change_id": "… | null",
            "reason": "… | null"
          },
          "pending_reconcile": false,
          "annotations": ["legacy", "reconcile: skipped"]
        }
      ]
    }
  ],
  "degraded": false
}
```

Field notes:

- `waiver` is `null` unless `bucket == "waived"`.
- `affected_change_ids` = ledger change stamps + reconcile correction change
  id (deduplicated, order-preserving) — the spec's "affected changes".
- `annotations` is a denormalized convenience for renderers; every annotation
  is derivable from other fields.
- `degraded: true` records that bd was unavailable and the gate degraded open
  (report may be partial; `verification` omitted → key absent).
- `verification: "blocked"` reports never accompany a landing — they are the
  audit trail of a refused attempt.

## `land-report.md` (structure, not schema)

1. Title + classification banner + run id + timestamp (+ "DRY RUN" marker).
2. Totals line.
3. Per spec: `## <owner_spec>` with three subsections (Resolved / Waived /
   Open — omitted when empty) rendering each entry's provenance as a compact
   definition list; waived entries include who/when/why; open entries include
   the resolution hint.
4. Footer: `Generated by maverick land <version>`.
